# WePicTool AI 工作流

这个目录保存当前仍需维护的 AI 提示词说明。小程序已经在云函数中调用真实的分类与抠图服务；实际运行行为以 `miniprogram/cloudfunctions/processOutfit/index.js` 为准，本文档用于解释和同步其提示词、标签与验收口径。

## 当前文件

- `classification-prompt.md`：阶段二图片部件识别提示词和返回格式。
- `matting-prompt.md`：阶段三抠图提示词和调用方式（代码默认 `qwen-image-edit-plus`，可由云函数环境变量覆盖）。
- [`../history/ai-research/`](../history/ai-research/)：已结束的选型、待办与提示词工程调研，仅供回溯。

## 使用原则

1. 分类标签固定，不让模型自由发挥标签。
2. 试穿全身图默认 `daily`，不自动抠整个人做白底。
3. 头像、包、配饰、日常合集、表情包和心情状态图不进入 MVP 主链路。
4. 每次修改提示词、模型默认值或调用方式，都要同步代码、本文档和当天迭代日志，并完成相应验证。
