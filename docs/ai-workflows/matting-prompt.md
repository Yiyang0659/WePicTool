# 抠图提示词

**阶段：** 阶段三  
**用途：** 对穿搭主链路图片（上衣、下装、鞋子）进行抠图，去除背景，生成白底图。  
**当前状态：** 2026-09-13 本地候选已改为 CloudBase 混元图生图，固定模型 `HY-Image-v3.0-I2I-ToB-v1.0.1`，不回退阿里云生图。尚未部署云函数；见 [部署步骤](hunyuan-deploy.md)。
**实际提示词：** `miniprogram/cloudfunctions/processOutfit/garmentPrompt.js` 的 `garmentPrompt(category)`。

## 当前提示词

```text
按上衣/下装/鞋子提取目标商品，去掉人体、首饰和其他服装；尽量保留原款式、颜色、图案、logo及纹理，侧拍或遮挡根据可见信息合理补全。完整居中、纯白背景、约92%画面占比，不裁边、不拉伸。完整指令以 garmentPrompt.js 为准。
```

## 调用方式

- SDK：`cloud.ai().createImageModel('hunyuan-image').generateImage(...)`。
- 模型：固定 `HY-Image-v3.0-I2I-ToB-v1.0.1`，下方为旧阿里云历史结构，不用于当前部署。
- 输入格式：多模态（图片 base64 + 提示词）
- 输出格式：返回抠图后的 PNG 图片 URL

```json
{
  "model": "qwen-image-edit-plus",
  "input": {
    "messages": [
      {
        "role": "user",
        "content": [
          { "image": "data:image/jpeg;base64,xxx" },
          { "text": "对这张图片进行抠图，去除原背景，将背景替换为纯白色，保留主体的完整轮廓，确保边缘干净" }
        ]
      }
    ]
  }
}
```

## 处理规则

- 只对 `tops`、`bottoms`、`shoes` 分类成功的图片做抠图。
- `others`（other_product / daily / unsupported / uncertain）不进入抠图链路。
- 抠图失败的图片保留原图，不影响整批结果。
- 抠图结果上传到云存储 `matted/` 目录。
- 结果项中保留 `originalUrl`，方便用户查看原图。
- AI 导入页对生成图调用 cardComposer：最大512像素边界测量、保守识别外侧白边，1024宽画布等比适配至限制边92%，默认3:4。读像素失败保留完整生成图，不盲裁；极浅无轮廓不能保证准确测量。其他素材和原图不参与裁白边。
- 无生成结果或合成失败明确放入待确认，不伪称标准化成功。图片质量仍需真实AI与真机验证。

## 验收标准

| 维度 | 要求 |
|------|------|
| 边缘干净程度 | 毛边、蕾丝、鞋带不能大面积残缺 |
| 浅色衣物可见性 | 白色衣服在白底上仍可辨认（需轻阴影或描边兜底） |
| 单张耗时 | 平均 <= 10 秒；以部署后真机实测为准 |
| 失败率 | 失败必须明确返回，不得保留原图冒充成功 |
| 单张失败 | 不阻断整批结果展示 |

## 测试素材

| 素材 | 数量 | 重点 |
|------|------|------|
| 上衣 | 5 | 白色、黑色、条纹、蕾丝/毛边、宽松版型 |
| 下装 | 5 | 牛仔裤、黑裤、半裙、短裤、浅色裙 |
| 鞋子 | 5 | 运动鞋、高跟鞋、靴子、浅色鞋、复杂鞋带 |
