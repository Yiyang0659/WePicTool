1. 微信开发者工具打开上述目录下 `miniprogram`，确认 AppID 和云环境是自己的真实小程序及 `cloud1-d0g1blfsde474b168`。
2. 云开发关联该环境；右键 `cloudfunctions/processOutfit` → **上传并部署：云端安装依赖**。不创建新函数，不修改 renderer 012–015。
3. 控制台进入该函数，确认 `DASHSCOPE_API_KEY` 保留且已保存。截图曾暴露旧 Key；若没有更换，先在百炼撤销并换新，不再发送含 Key 的截图。
4. 核对执行超时：官方生图示例建议函数 900 秒、SDK 150000 毫秒；代码已配置后者。90 秒可能在生成结束前终止。控制台若允许，可按官方建议设置900秒；这不保证客户端等待同样长。现有整批同步链路仍需真机测量，若客户端先超时，需要后续异步任务/轮询改造，不反复点击造成重复消耗。
5. 编译后先在实际小程序选择 **1 张上衣** 测试。确认分类回填、白底成图、衣服构图与保存。再测3张、最大批次；任何超时先查日志，不以本地 mock 通过替代。
6. CloudBase 生图用量核对是否增长；百炼核对实际调用为 `qwen3.8-flash`。用量统计有延迟，最终以账单抵扣和有效期为准。
7. 测试通过才在开发者工具上传小程序版本并设体验版。正式提交审核另须完成 `docs/current.md` 发布门禁，当前不宣称已可发布。
