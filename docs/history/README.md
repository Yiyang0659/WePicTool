# 历史资料

本目录保存已经结束的阶段记录、旧决策和旧调研，便于追溯“当时为什么这样做”。

它们**不是当前开发依据**：开始新任务时，先看根目录 `AGENTS.md`，再看 `../current.md`、`../roadmap.md` 和相关的产品、技术文档。

| 文件或目录 | 内容 | 使用方式 |
| --- | --- | --- |
| `project-status-2026-07-08-to-19.md` | 2026-07-08 至 07-19 的阶段状态与迭代记录 | 查历史交付、旧验证和当时风险 |
| `legacy-notes.md` | 已过时或未采纳的旧方案与早期决策 | 仅在需要了解背景时查阅 |
| `ai-research/` | 已结束的抠图选型、提示词工程和工作流调研 | 作为实验依据，不当作运行配置 |
