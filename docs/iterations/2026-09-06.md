## 字体服务断连空白预览修复

用户在趣味字画编辑页遇到空白画布和 `loadFontFace:fail ... ECONNREFUSED 127.0.0.1:8080`。检查确认字体文件本身没有损坏，而是本地 renderer 进程已经停止、8080 端口无人监听；原编辑页只把字体组件错误原样弹出，没有接入候选页已有的服务端预览降级，因此整个画布留白。

修复结果：

- 按显式开发模式重新启动当前工作树的 `fun-card-renderer`；`LXGWMarkerGothic-Regular.ttf` 实测返回 HTTP 200，下载长度 3,179,616 字节；
- 编辑页监听字体不可用和 Canvas 渲染失败，失败时按当前项目请求服务端低清预览，并按候选与当前卡片索引显示对应图片；
- 切换卡片时同步切换降级图片；文字、样式、装饰或顺序发生变化后废弃旧预览，避免展示过期结果；
- 本地字体和服务端预览同时失败时，不清空项目、不伪装成系统字体，改为显示“手写预览暂时没连上”和“重新加载”；
- 候选页把 `fontunavailable` 接入已有 `onCanvasError`，字体错误和其他 Canvas 错误共用同一套只请求一次的服务端预览降级；
- 底层 `ECONNREFUSED` 不再作为用户提示展示。

开发者工具回归：

- 在 iPhone 12/13 Pro 模拟尺寸从首页进入趣味字画示例，再进入“自己改改”；
- 编辑页首张卡片重新显示“我本来想说”的手写内容，未出现空白画布或底层网络错误 toast；
