## 趣味字画跨设备字体 CDN 修复

用户在 Android 真机上发现趣味字画三套候选图和编辑画布同时空白，并询问是否可以改用云缓存以支持不同设备。排查确认小程序字体配置仍为 `http://127.0.0.1:8080`，且开发电脑 8080 当时无服务监听。在真机上该回环地址始终指向手机本身，不能作为跨设备方案。

实施结果：

- 通过 CloudBase CLI 登录并确认唯一目标环境为 `cloud1-d0g1blfsde474b168`；
- 使用安全上传与远端校验，把 `LXGWMarkerGothic-Regular.ttf`、`SmileySans-Oblique.ttf` 和 `MaShanZheng-Regular.ttf` 发布到静态托管 `font/` 路径；
- 静态托管返回 CDN 基地址 `https://cloud1-d0g1blfsde474b168-1451421513.tcloudbaseapp.com`，三个字体文件通过远端文件列表和 HTTP HEAD 双重校验，状态码均为 200；
- 小程序 `FUN_CARD_RENDERER_URL` 切换为该 HTTPS/CDN 地址，候选页和编辑页不再依赖开发电脑 IP 或本地 8080；
- 字体静态公开分发与 renderer POST 私有调用正式分离；不把约 11 MiB 的三款字体打入小程序主包，也不用系统字体伪装手写字感。
