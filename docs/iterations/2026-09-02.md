## 趣味字画阶段一 Task 6 Fix Round 1

### 修复内容

1. **视觉场景严格校验**：每个文字层必须显式携带四个已注册 `effectKey` 之一；背景对象只接受 `{ assetKey, color }`，必须包含已注册且与 `stylePackId` 对应的背景键。缺失、未知、跨视觉包和额外图片/渐变形式均在审核或绘制前返回 `INVALID_REQUEST`。实际 PNG 画笔同步移除 `marker-bold` 静默默认值，直接调用时遇到缺失/未知效果也会失败。
2. **三候选预览请求级回滚**：`/preview-stack` 记录本次请求内每套已上传卡片；候选 2/3 的绘制、上传或响应顺序/身份校验失败时，除当前候选由场景渲染器清理的部分上传外，还会删除此前候选的全部上传。清理为尽力执行，清理自身异常不覆盖稳定的 `RENDER_FAILED` 响应。
3. **内容审核错误码收敛**：云托管生产审核与既有 `contentGuard` 一致，仅微信官方 `errCode=87014` 映射为 `CONTENT_UNSAFE` / 403；权限、配额、配置、未知 API 响应、空响应和抛错均映射为 `SAFETY_UNAVAILABLE` / 503。本地开发离线审核行为保持不变。
4. **超限 HTTP 请求稳定响应**：超过 2 MiB 后不再销毁请求 socket；服务停止累积正文但继续排空输入，在 `end` 后稳定返回 JSON `INVALID_REQUEST` / 400。
