# 内容区手写与手写新卡实施计划

依据已确认同名设计；仅在当前功能分支实施，不部署、不切流。

1. handwritingLibrary：兼容旧草稿，增加背景颜色和用途元数据；缩略图按背景显示，保持10份/2MB限制和副本隔离。
2. funTextProject / sceneComposer：新增带稳定sceneId的空白场景，在当前卡后插入，最多8张；保留模板逻辑卡，不用位置反查用户新卡。支持纯色背景、恢复/撤销、新卡添加文字；切换风格不丢用户新卡和笔迹。
3. sceneValidator：增加明确solid背景协议，限制HEX颜色且不可带模板变体，保留其他白名单。既有renderer按背景颜色绘制、strokes经图片审核；用本地真实Canvas及mock审核测试验证，不请求线上。
4. fun-text-editor：手写/草稿块移到内容输入下；用途、背景色、目标卡文案和提交状态；新卡插入后选中；样式内纯色板；内容内选中手写可编辑/删除。沿用已有变换手势与导出缓存失效。
5. 发布兼容：旧012/015不识别solid协议，未获部署授权。客户端增加默认关闭的服务能力声明；含新卡/solid背景最终保存提前给兼容提示，不向旧服务发必失败审核请求。既有模板保存不受影响。待后端另行部署验收后开启能力声明。
6. 回归：迁移位置、草稿旧数据、插入/删后新增/恢复/撤销、目标绑定、背景和笔迹保留、全笔迹适配、payload校验、成图像素与审核失败门禁；跑全部治理检查并更新README/current/迭代。开发者工具可用时本地视觉检查，真机保存不冒充完成。
