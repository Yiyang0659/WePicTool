# 编辑页动态保存弹窗

用户已确认粉紫色效果图并要求实施。保留现有审核、成图及保存流程。

1. 白色圆角卡片、淡紫边框、动态旋转环/呼吸步骤和粉紫进度条替换编辑页原生 loading。
2. 云端一次返回审核与成图结果，等待期间统一显示“正在审核并生成”，不虚构审核完成事件或百分比；返回成功后显示“正在准备图片”。
3. 相册阶段显示当前张数及已成功保存数量，进度仅在相册成功回调后增长。单张为 1/1，失败续存保留已保存进度。
4. 遮罩阻止编辑与重复触发；错误前关闭浮层，卸载后不写入页面状态。
5. 新增页面异步状态与真实串行导出回调回归，执行治理检查。真机动画/Canvas遮挡仍需人工复核。无需云端部署。
