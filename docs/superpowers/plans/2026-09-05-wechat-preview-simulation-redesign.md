# 微信效果预览页仿真改版实施计划

**日期：** 2026-09-05
**依据：** `docs/superpowers/specs/2026-09-05-wechat-preview-simulation-redesign.md`
**状态：** 已按用户确认及两段真实微信录屏实施；自动化与开发者工具关键交互通过，待双端真机验收

## 目标

把 `pages/preview/preview` 重构为固定一屏的微信聊天预演壳层：系统区、会话导航和底部输入栏不随内容移动，只有聊天消息区纵向滚动；图片消息按真机微信截图使用约 38vw 的紧凑叠图，穿搭缩略卡接近 3:4。横向手势由顶卡跟手、后卡同步补位、旧顶卡回到尾层组成连续循环；展开后改成逐张独立消息并禁用横滑。新增一颗太阳/月亮合并分段按钮，按腾讯官方 WeUI 普通/深色主题变量即时切换并保存用户选择。

## 实施步骤

### 1. 先更新布局与主题测试

- 修改 `tests/preview-layout.test.cjs`；
- 覆盖新的 38vw/164px 紧凑图片舞台、3:4 穿搭缩略框、横竖图比例和窄屏剩余消息通道；
- 检查 WXML 不再包含模拟状态栏、第二套省略号和悬浮组名；
- 检查固定壳层、唯一滚动区、普通/深色模式合并按钮和预览模式输入栏结构。

### 2. 重写图片消息布局纯函数

- 修改 `miniprogram/utils/previewLayout.js`；
- 根据视口宽度扣除安全边距、头像、展开按钮、间距和牌堆露边后计算舞台宽度；
- 图片最大宽度为 `min(38vw, 164px)`，最大高度为 `min(51vw, 219px)`；穿搭 4:5 输出在折叠态居中填充接近 3:4 的缩略框；
- 返回实际舞台与图片尺寸，供手势阈值和每组消息行共同使用。

### 3. 重构固定微信壳层

- 修改 `preview.wxml / preview.wxss / preview.js`；
- 删除硬编码状态栏和额外省略号；
- 根据系统状态栏与小程序胶囊计算自定义导航尺寸和右侧避让；
- 根页面固定在实际可用视口，禁止外层滚动；导航和输入栏固定，中间 `scroll-view` 为唯一纵向滚动区；
- 消息改为右对齐的“展开胶囊 + 牌堆 + 头像”，移除聊天流中的组名；
- 横纵方向锁定后，纵向交还消息区，横向只变换当前顶层卡。

### 4. 实现普通/深色模式合并按钮

- 用 WXML/WXSS 绘制与用户参考一致的线性太阳、月亮图标，不把带网格背景的截图作为运行时图片素材；
- 两个图标放进同一颗圆角分段按钮，整颗按钮点击切换；
- 使用官方 WeUI 普通/深色基础色值；
- 默认读取系统主题，之后优先使用本地保存选择；
- 添加无障碍文案与失败回退。

### 5. 收口预览交互

- 首次提示只说明“左右滑动切换 · 点展开查看全部”；
- 展开从当前顶层开始，收起保持当前顶层；
- 长按只保留“保存这张/保存这一组”，删除无法兑现的图片转发；
- 底部输入栏标记“预览模式”，点击说明保存后回微信发送；
- 图片失败、空数据和大图查看保留可恢复路径。

### 5.1 依据真实微信录屏校准牌堆状态机

- 把原来的“只有顶卡移动，飞出结束后再切 class”改为拖动阶段后卡同步补位；
- 方向锁加入斜滑迟滞，快滑加入 10px 最小有效位移；
- 完成切换时使用约一张卡宽、±9° 小角度和 190ms 过渡，旧顶卡在尾层轻淡入；
- 展开态按当前顶层顺序纵向展示全部图片，每张单独带头像且不再响应横滑；收起恢复同一顶层；
- 为方向判定、阈值、三节点补位、单组隔离、展开顺序和收起恢复增加回归测试。

### 6. 同步规格并验证

- 更新 `docs/product/TECHNICAL_SPEC.md`、`docs/current.md` 和 `docs/iterations/2026-09-05.md`；
- 运行针对性测试；
- 运行 `npm test && npm run check:syntax && npm run check:miniprogram && npm run lint && npm run check:docs`；
- 运行 `git diff --check`；
- 能调用微信开发者工具时执行普通编译；iOS/Android 的安全区、回弹和真实微信尺寸对照继续作为真机验收项。

## 非目标

- 不修改导出 manifest、编号、封面或保存顺序；
- 不向微信指定好友直接发送图片；
- 不改动其他创作页面的全局主题；
- 不把主题切换写回系统或微信客户端设置。
