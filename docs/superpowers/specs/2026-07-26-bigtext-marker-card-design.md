# 大字滑卡：粗颗粒马克笔白卡设计

## 目标

将当前规整书法字卡改为参考图中的“粗马克笔手写”效果：黑色大字有明显颗粒、毛边和轻微不规则性；每张卡都是干净的白色圆角卡，并带一枚原创小贴纸。只改最终导出的 PNG 卡片，不生成真人背景、头像或仿微信聊天截图。

## 视觉规则

- 卡片为 1080 × 1080 PNG，背景纯白 `#FFFFFF`，圆角 56px，无描边、无纸张纹理、无阴影。
- 内容字使用 OFL 1.1 授权的 `LXGW WenKai` 作为底字形；它提供日常手写感，不采用书法感更强的马善政。
- 内容字为近黑色 `#171717`。先填充字形，再以圆角连接的同色描边加粗，使笔画呈现粗记号笔效果。
- 对字形 alpha 蒙版叠加确定性颗粒：每张卡的种子来自 `taskId + order`，因此同一张已生成卡不会随重开页面变化。
  - 外沿轻微锯齿：0–3px；
  - 笔画内部稀疏白色颗粒：覆盖面积 2%–4%；
  - 墨色透明度仅在 90%–100% 之间波动，不出现浅灰字。
- 内容字按卡片独立的确定性参数变换：旋转 -3° 至 3°、缩放 94% 至 106%、X/Y 偏移各不超过 42px。字保持完整可读，不允许裁切。
- 单字占可用区域的 68%–78%；多字辅助卡采用同一笔触但缩小到 150px–190px，并居中排版。
- 每张卡右下或右上放一枚 110px–156px 的原创贴纸。首版内置 12 枚简单彩色涂鸦（星星、笑脸、爱心、闪电、花、小动物脸等），不使用蜡笔小新或第三方角色素材。
- 贴纸位置、图案与旋转同样由种子确定；与文字最小间距 32px，不能遮住关键笔画。

## 交互和范围

- 首页、输入规则、内容安全审核、主题选择、保存、微信预览和历史记录保持不变。
- 默认主题替换为“马克笔白卡”；夜写和蓝紫主题沿用现有配色，但也使用同一粗颗粒笔触与贴纸系统。
- 编辑页中的预览明确标注为“排版预览”；最终效果只以云端返回 PNG 为准。编辑页预览同步改成白色叠卡示意，避免继续展示规整字体。
- 结果页继续显示最终 PNG；预览页不伪造参考视频中的真人照片或聊天气泡。

## 技术方案

1. 云托管渲染器引入 `LXGWWenKai-Regular.ttf` 与 OFL 许可证，并注册为 `LXGWWenKai`。
2. 渲染器按 `taskId` 和卡片 order 生成伪随机参数；任务创建时将稳定 `taskId` 传入渲染流程。
3. 使用 Canvas 的 `fillText`、`strokeText` 与离屏 alpha 蒙版绘制字形，再在蒙版内写入少量透明像素形成笔触颗粒。
4. 贴纸使用仓库内原创 SVG/PNG 资产绘制；不依赖网络图片、AI 生图或用户设备字体。
5. 渲染服务的响应格式和全量失败回滚策略保持现有契约；新增测试验证：同种子稳定输出、不同卡片参数不完全一致、贴纸不覆盖文字区域。

## 验收标准

以“今、你、开、心”四张卡为固定验收样例：

1. 观感是粗马克笔手写，而非书法、印刷字体或规整 UI 字体。
2. 四张卡的字位、旋转或大小存在可见但克制的差异。
3. 每张白卡均有一枚原创小贴纸，贴纸不遮字。
4. 文字在 375px 宽手机预览中仍清晰可读。
5. 同一任务重新打开时卡片 URL 与视觉内容不变化；审核拒绝和任一渲染失败仍不产生部分结果。
6. 不使用 AI 文生图、不复制参考视频中的人物、头像、聊天内容或版权角色素材。
