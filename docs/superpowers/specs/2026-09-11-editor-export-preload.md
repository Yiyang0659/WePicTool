# 编辑快捷导出与预加载设计

依据用户本轮明确要求：依次实现参考图按钮和此前确认的整套/三字体预加载。不改变画布比例或全局视觉。

1. 画布下用保存当前页、保存整组替换改字提示，内容标签中的改字入口保留。底部微信预览与完成固定，留安全区与占位，弹窗期间隐藏底栏。
2. 保存/微信预览须先通过现有最终渲染与编号物化，保存当前页按sceneId选图，整组沿用串行保存；失败提示且保留编辑。完成沿用结果页。点击时锁定项目快照，编辑变更不能导出旧图。图片预览缓存不作最终导出。
3. 预加载以候选生成完成为起点，不猜未知用户文字。三封面优先，随后卡片与三字体变体，进入编辑后优先当前卡、该组与三字体；并发2，主动操作优先，替换队列取消未开始的旧任务。预热增加现有服务请求/流量，但不新增云资源。
4. 会话内共享缓存最多60张，图片下载到临时本地路径，按LRU保留；文件失效重取，不承诺跨重启持久。命中同步显示，不先清空/显示加载。同卡未命中保留旧图并提示；切卡未命中不得冒用旧卡。网络失败可重试；不保证首次或任意新组合零等待。
5. 不新建云资源、不变更renderer协议，不合并/推送。真实相册权限、网络时延、双端固定栏需要真机验收。
