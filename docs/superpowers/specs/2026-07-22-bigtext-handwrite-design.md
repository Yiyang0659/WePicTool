# 大字滑卡（默认手写体）设计

**日期：** 2026-07-22  
**状态：** 已确认，待实现

## 目标与边界

阶段六首发只交付「大字滑卡」，让用户输入一句 1–20 字的文本，生成可保存、可在微信预览中逐张滑动的文字卡。默认视觉为米白纸卡上的中文手写体，最后一张允许使用主题强调色。

本次不交付剧情滑卡、自由编辑器、自定义颜色或 AI 生成。大字卡由云端文字渲染服务输出；云端仅执行内容安全检查与授权字体渲染，不调用生成模型。

## 用户体验

1. 首页「大字滑卡」入口由“即将上线”切换为可点击。
2. 编辑页提供一句话输入、实时字符数、三套主题选择和卡片数量预览。
3. 用户点击生成后，先调用统一的 `contentGuard` 进行文本审核；不安全或审核失败时不输出卡片。
4. 审核通过后，云端按字符生成 1:1 手写卡并进入模板结果页。
5. 结果页展示一叠卡片，可预览、保存单张、保存全部，并进入微信聊天式预览。
6. 本地记录保存文本、主题和卡片规格；再次打开时重新渲染，避免依赖临时图片路径。

### 最少三张的规则

微信叠图最少需要三张。正常输入一字一张；不足三张时插入固定辅助卡：

| 输入长度 | 输出顺序 |
| --- | --- |
| 1 | `滑一下` → 用户文字 → `就这一个字` |
| 2 | 第 1 字 → 第 2 字 → `继续滑 →` |
| 3–20 | 逐字输出 |

编辑页要明确提示补了几张辅助卡，辅助卡不能伪装成用户输入。

## 视觉与主题

默认主题是「手写纸卡」：米白背景、细内框、中文手写字体、轻微错落的纸卡叠放。最后一张字可用红色强调，以形成收尾停顿。

首版固定提供：

- 手写纸卡：米白底、深墨字、末张红色强调。
- 夜写：深色底、白色手写字。
- 蓝紫手写：蓝紫渐变底、白色手写字。

云端渲染服务内置一款授权可商用、支持中文的手写字体，并输出 PNG 卡片到云存储。前端只下载生成图，不依赖用户设备字体，因此 iOS 和 Android 的字形一致。字体加载、文字绘制或上传失败时，服务返回明确错误；前端不改用系统字体，以避免同一任务跨设备风格不一致。

## 架构与数据

新增独立的模板任务，不复用穿搭的分类、抠图和分组数据：

```js
{
  taskId: 'text_xxx',
  mode: 'bigtext',
  type: 'bigtext',
  status: 'done',
  sourceText: '生日快乐',
  themeKey: 'handwrite-paper',
  cards: [{ cardId, text, role, order, localPath }],
  createdAt: 0
}
```

- `utils/textCard.js` 只负责安全的字符拆分、补卡规则、主题规格和任务组装。
- `cloudhosting/text-card-renderer/` 是独立容器服务，负责二次调用内容安全检查、加载授权字体、绘制 PNG 并上传云存储。选择云托管而不是云函数，因为现有 CloudBase 云函数不支持字体渲染所需的原生图形依赖。
- `pages/bigtext/` 只负责输入、主题选择、审核请求和创建任务。
- `pages/template-result/` 只负责模板任务的结果展示、保存与预览跳转。
- `pages/preview/` 增加模板任务适配分支，保留现有穿搭渲染路径不变。
- `pages/record/` 增加 `bigtext` 类型元数据；再次打开传递任务规格，由结果页重新生成卡片。

`Array.from(sourceText)` 用于拆分字符，避免 emoji 和代理对被截断。首版不承诺复杂 emoji 或合字的视觉效果，输入框会按可渲染字符数限制到 20。

## 错误处理

- 空文本、全空白文本或超过 20 字：编辑页禁止生成并提示原因。
- 内容审核拒绝：保留输入和主题，提示修改文本。
- 内容审核网络失败：不生成，提示稍后重试；生产模式不绕过审核。
- 字体加载或云端绘制失败：不写入不完整记录，提示用户重试。
- 单张渲染或上传失败：整批任务标记失败，保留输入和主题，用户可重试。
- 保存相册失败：沿用现有授权与设置页引导。

## 验收与测试

- 单元测试覆盖字符拆分、1/2 字补卡、3–20 字逐字卡、主题规格与非法输入。
- 审核通过、拒绝、失败三条分支都有行为测试。
- 云托管服务测试验证字体渲染、云存储上传和单张失败返回。
- 开发者工具验证三种主题、预览、单张/全部保存和历史重开。
- iOS 与 Android 真机各验证一次：手写字体渲染结果、保存相册、微信叠图预览。
- 回归运行 `npm test`、`npm run check:syntax` 和 `npm run check:miniprogram`。
