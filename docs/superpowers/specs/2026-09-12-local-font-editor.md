# 趣味字画完全本机编辑

状态：用户在本次请求确认本机编辑方向，按此边界实施；未发布。

## 目标与边界

输入→规则候选→改字/换字体/换背景/装饰/手写/草稿全部本机运行，不调用审核、AI规划或renderer预览。保持现有画布与按钮布局。三款授权字体随小程序资源分包提供，以OpenType轮廓在Canvas绘制，不依赖系统字体或wx.loadFontFace/CDN。首次获取代码分包可能联网，下载完后的编辑不需要业务网络。未覆盖字符明确提示，不静默使用默认字体。

仅改趣味字画，穿搭AI等其他玩法保持原状。“用这套”在本机模式进入编辑；保存、完成制作与现有微信成品预览仍走可信云端审核/成图链路。当前服务端45009并不因本机编辑而消失。逐图审核、永久成品凭据、完全离线保存不在本轮偷偷启用；这些需要后续独立的导出协议与平台合规确认。未经审核本机画布不能传入可保存的共享manifest。

## 实现与风险

原TTF拆为11个资源分包，每包小于2MiB。通过require.async引用携带Base64数据的模块、wx.base64ToArrayBuffer解码后解析，每款字体解析一次。保留授权并校验重组SHA256。不使用小游戏wx.loadSubpackage，不直接读取包内TTF（实测permission denied）。原字体11.1MiB，编码资源约14.9MiB（未压缩），纳入总包预检。入口仅预热字体，过期场景不绘制。

字形轮廓保证来源固定，抗锯齿、基线及特殊文字排版可能与服务器有细微差异；必须开发者工具冒烟及后续iOS/Android真机验收。字体资源增加约11MiB，首次分包耗时、低端机解析内存和离线首次使用是明确限制。草稿仍仅本机，清理/换设备不能恢复；手写不会自动变成可输入字体。
