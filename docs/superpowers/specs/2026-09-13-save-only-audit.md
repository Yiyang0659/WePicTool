# 趣味字画保存审核与显式排序

用户已于本轮确认聊天方案。

- 横向卡片列表仅浏览，取消触摸拖动排序。每卡下有前移、后移、删除；一次移动一位，约200ms平移动画，跟随sceneId保持选中，边界禁用，至少留一张，删除可撤销。封面与导出顺序同步。
- 编辑页微信预览、完成进入结果页、结果页微信预览及返回编辑均不调用审核服务；本机字体轮廓、背景、装饰和手写合成预览图。首次字体/合成允许短暂等待和可恢复错误，不以系统字体或漏笔迹静默替代。
- 只有编辑页保存当前页、保存整组以及结果页按顺序保存调用最终审核与成图。未审核预览缓存不能作为已审核成品；保存失败保留编辑、拒绝审核不写相册。现有单页保存的整组审核实现不在本次优化调用粒度。
- 不修改穿搭叠图，不切流、不部署、不发布，不扩充自由创作功能。历史记录不能仅凭本地字段跳过本会话保存审核。

验收：预览/导航零审核请求；保存审核成功后才写相册；失败无写入；重复点击合并；移动/删除/撤销顺序与笔迹保持。少于三张沿用现有普通图片预览规则，不承诺微信叠图。
