# 首页双玩法共享预览改版设计说明

**日期：** 2026-09-05
**状态：** 用户已确认；分支实现与自动化验证完成，待双端真机验收
**范围：** 微信小程序首页 `pages/index/index`

## 1. 设计结论

首页以用户提供的移动端效果图为主要视觉参考，从“多个大型演示、入口和教程纵向堆叠”改成“先选任务，再在同一个区域理解和开始”。首页首屏只回答一个问题：用户今天想做「分层换装」还是「趣味字画」。

两种玩法使用同一块主预览面板，不再上下各占一个完整演示区。切换玩法时只替换面板内容和对应操作按钮，保留各玩法已经滑到的位置。更多工具放在主任务之后；完整使用教程从首页移除，在用户完成预览或保存时按上下文展示。

## 2. 当前问题

当前首页依次放置品牌区、四叠演示、趣味字画大图演示、分层换装旗舰卡、热门模板、AI 工具、后续玩法和完整教程。同一玩法重复出现，用户必须滚动后才能找到真正的开始按钮。

四叠演示中两张 `.layered-stack-edge` 是没有内容的装饰视图。它们原本用于表示“后面还有卡片”，但在白色卡片上表现为模糊空白块，用户无法识别其含义。本次删除这种空白占位，不再用无内容的卡片表达可滑动。

## 3. 首页信息架构

首页从上到下固定为四层：

1. **任务问题**：标题“今天想做什么？”，不再重复放置大面积品牌介绍；导航栏标题继续显示“滑一叠”。
2. **玩法选择**：并排显示「分层换装」和「趣味字画」两张等宽选择卡。
3. **共享主预览**：只渲染当前选择玩法的演示、说明和行动按钮。
4. **更多工具**：紧凑展示现有 AI 穿搭整理和少量明确标记状态的后续玩法。

底部“首页 / 记录 / 我的”原生 Tab 保持不变。

## 4. 视觉规则

### 4.1 页面基调

- 页面背景使用很浅的冷灰紫，建议 `#F7F8FC`；主要面板使用白色。
- 一级文字使用近黑色 `#151728`，次级文字使用灰紫 `#8B90A6`。
- 圆角和阴影保持轻量，避免每个区块都形成独立“大卡片”。
- 首屏不使用空白骨架卡、毛玻璃模糊块或无法点击的装饰按钮。

### 4.2 两种玩法颜色

- 分层换装主色为蓝紫 `#6670F6`，允许按钮使用 `#8980FF → #6470F7` 的轻渐变。
- 趣味字画主色为粉色 `#ED65B5`，仅用于图标、选中边框和当前状态点缀。
- 未选中的玩法卡维持白色，不用大面积染色；选中状态通过边框、浅色底和右上角勾选表达。

### 4.3 首屏高度

常见手机尺寸下，玩法选择、完整共享预览和两个主操作必须在底部 Tab 上方可见。更多工具可以从首屏底部露出，但不能挤压主任务按钮。趣味字画与分层换装切换后共享面板高度保持稳定，避免页面跳动。

## 5. 分层换装共享预览

### 5.1 内容结构

面板标题使用“分层换装”，说明为“四个部位独立滑动，搭配出你的专属风格”。左侧或主体区域显示头像/发型、上衣、下装、鞋子四行；右侧显示“当前组合”摘要。

每个部位行包含：

- 部位图标与名称；
- 当前序号，如 `1 / 3`；
- 三个真实素材缩略图，当前项显示蓝紫描边；
- 可点击的左右切换区域。

不得再显示两张没有内容的白色叠卡。为了表达可继续滑动，只使用真实的相邻缩略图、左右箭头和 `1 / 3`。

### 5.2 当前组合

当前组合只汇总四行已选择的真实素材，不模拟 AI 试穿，也不把素材伪装成已经穿在真人身上。视觉上可把四个当前项按头部、上衣、下装、鞋子纵向排列成纸娃娃式摘要；素材比例不适合时使用 `aspectFit`，不得拉伸。

任何一行切换后，组合摘要立即同步更新；其他三行的选择不重置。

### 5.3 操作

- 主按钮“直接试玩”：进入 `/pages/dressup/dressup?mode=demo`。
- 次按钮“上传我的素材”：进入 `/pages/dressup/dressup?mode=upload`。
- 首页预览不请求相册、不保存项目，也不触发 AI。

## 6. 趣味字画共享预览

切换到「趣味字画」后，在同一面板展示现有五张真实示例 PNG。用户左右滑动，面板内显示 `当前 / 5`；保留已滑到的索引，切换到分层换装再返回时不重置。

- 主按钮“用示例试玩”：沿用固定已审核文案进入三候选页，不调用输入安全云函数。
- 次按钮“输入我的一句话”：进入 `/pages/fun-text/fun-text`。
- `ENABLE_FUN_TEXT_STACK_ENTRY=false` 时静态示例仍可查看，两个创作入口按现有安全口径提示“暂不可用”，不得绕过紧急关闭。

## 7. 更多工具

参考图中的“风格滤镜、图片编辑、拼图排版”不属于当前已实现范围，本次不能伪装成可用能力。

更多工具区采用参考图的四列紧凑布局，但内容必须来自真实状态：

- AI 穿搭整理：可用，点击沿用 `onChooseMedia`；
- 胶片相册、前后对比：标记“即将上线”，点击统一提示；
- 更多玩法：进入统一的“敬请期待”提示，不新增空页面。

旧“热门模板”“本期主玩法”“怎么玩”和重复的示例入口从首页移除。玩法教程在编辑、预览和保存完成时按用户当前任务展示。

## 8. 用户旅程

### 新用户

```text
进入首页
→ 选择分层换装或趣味字画
→ 在共享面板内看到真实效果
→ 直接试玩低成本示例
→ 编辑或选择方案
→ 朋友视角预览
→ 按序保存
→ 此时学习微信发送步骤
```

### 有明确目标的用户

```text
进入首页
→ 选择玩法
→ 直接点击“上传我的素材”或“输入我的一句话”
→ 完成对应创作流程
```

首页不要求用户提前阅读所有功能说明，也不在用户尚未生成内容时教授发送步骤。

## 9. 验收标准

- 首页不存在 `.layered-stack-edge` 或其他无内容白色叠卡；
- 分层换装与趣味字画只占用一个共享主预览位置；
- 两种玩法切换后各自的演示索引保持；
- 四个换装部位独立切换，改变一行不重置其他行；
- 当前组合只由真实本地素材组成，不宣称 AI 试穿；
- “直接试玩”“上传我的素材”“用示例试玩”“输入我的一句话”进入正确现有路径；
- 趣味字画紧急开关继续阻断所有创作入口；
- 更多工具不把未实现能力展示成可用；
- 常见真机尺寸下，无需纵向滚动即可看到当前玩法的完整预览和两个主操作；
- 记录页、我的页以及首页原有 AI 选图确认流程行为不变。
