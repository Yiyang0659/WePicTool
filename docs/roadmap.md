# WePicTool 路线图

**最后更新：** 2026-09-06
**总方向：** 先固定“微信发送前素材处理与玩法化”的产品外壳并完成共同基线验收，再合入主线；主线稳定前不继续堆叠新玩法。

路线图分成两层：`G` 表示当前必须依次通过的交付门禁，`P` 表示通过门禁后的产品能力顺序。门禁没有通过时，产品能力即使已有分支代码也不能写成“完成”或“可发布”。

- 分层云换装内置素材主包超限、Canvas 路径和开发者工具 `http://tmp` 协议问题已修复并有回归；
- 微信效果预览页仿真改版已完成分支实现、全量自动化和开发者工具关键交互验证；
- 当前功能分支已把分层换装与独立 AI 穿搭入口收敛为“穿搭叠图”：同一工作台支持手动/AI 混合添加、AI 复核和待确认归类；尚待真机验收与合入主线；

- 当前集成状态已提交为 `0f55a38`，并通过合并提交 `f52a8c8` 进入 `main`；来源分支转为只读追溯点。

## G2：发布范围与云端生产门禁

**目标：** 决定“这一版到底发布什么”，并只为纳入范围的能力建立生产证据。

**必须决定：**

- 个人主体继续发布非 AI 路径，还是申请企业主体后包含 AI/深度合成能力；
- 趣味字画 P2.2 AI 故事规划是否进入首个发布包；
- `ENABLE_FUN_TEXT_STACK_ENTRY` 的发布默认值；
- 穿搭 AI 工具在审核范围未确定时是否隐藏或仅保留测试入口。

**若趣味字画云端能力纳入发布，必须完成：**

- Node 20/bookworm-slim Docker 构建；
- CloudBase 服务、权限、`callContainer`、平台公网关闭和字体精确网关；
- 48 小时对象生命周期与残留检查；
- preview/render/字体/403/503/超时/内容拒绝线上冒烟；
- P2.2 纳入时再部署 `planFunTextStory`、配置服务端模型密钥并验证规则兜底。

**当前发布预检：** `npm run check:miniprogram:release` 退出 1；阻断项为缺少 `call-container-only` 访问模式声明、字体地址仍使用 HTTP、字体地址仍指向本机 loopback。普通开发预检通过不解除这些发布阻断。

**完成条件：** 发布清单、未发布清单、配置证据、回滚开关和线上冒烟全部可追溯；生产状态才能从 NOT READY 改为候选可发布。

## G3：合入 `main` 与发布

**目标：** 把经过 G0–G2 的共同基线作为唯一主线，结束多分支漂移。

**当前状态：** 用户为继续测试于 2026-09-06 明确要求先合入 `main`，代码合并已完成；G1/G2 尚未通过，因此“合入”完成不代表“可发布”，本门禁的生产发布部分仍未完成。

**步骤：**

1. 最终代码审查和差异清单；
2. 运行治理规定的完整检查与 `git diff --check`；
3. 记录部署步骤、风险和回滚条件；
4. 合入 `main` 后再次更新 `current.md`；
5. 只有实际合并或发布的用户能力才写入 `changelog.md`。

**完成条件：** `main` 与文档一致；来源分支转为只读历史；后续开发从新主线开分支。

**状态：** `main` 已实现，等待 G1 双端验收与 G2 生产门禁。

**范围：** 内置试玩、用户素材、系统/用户/AI 混用、手动与 AI 双添加方式、AI 结果复核、待确认归类、头像/发型/上衣/下装/鞋子四组、删除排序、首图、独立预览、按组导出、素材来源与版本。

**完成条件：** 手动路径不依赖 AI；每组不足 3 张不伪造叠图；四叠真机发送通过；首页与素材包由注册数据驱动。

## P3：非 AI 照片玩法

**顺序：** 胶片相册 → 前后对比 → 无缝画卷。

**进入条件：** G3 完成，设计系统已确认并完成第一轮无视觉变化迁移，玩法注册、预览、manifest、保存和记录接口稳定。

**规则：** 每个玩法只新增输入规则、生成器和注册项；不得复制页面外壳、结果页或保存队列。不做复杂调色和专业修图。

## P4：节奏、故事与群聊互动

**顺序：** 内置翻页动画 → 剧情反转 → 盲盒抽签 → 自定义 GIF/短视频抽帧。

剧情反转复用趣味字画策略与场景系统；盲盒复用文本安全和统一导出；自定义抽帧只有在云托管耗时、体积、费用和兼容性验证后进入实施。

## P5：兴趣实验

资料打包、拼图揭秘、用户自由手绘、更多素材包和其他个人兴趣玩法。实验不得破坏统一叠图管线；没有复用价值的能力不进入首页主入口。

## 已替代与长期不做

- 旧大字滑卡：由趣味字画替代，只保留技术资产；
- AI 最终中文图片生成：准确性、可编辑性和复现性不满足要求；
- 通用图片编辑器、模板商城、账号/付费体系：不在当前路线；
- 小程序直接把多图发送给指定微信好友：平台能力不支持，不作产品承诺；
- 通过文件名控制系统相册/微信选择器顺序：API 不支持，以图片内可见序号和用户确认代替。
