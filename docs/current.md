# WePicTool 当前状态

**最后更新：** 2026-09-02

## 当前阶段

玩法架构设计、P1 共享底座与趣味字画阶段一已全部完成；趣味字画 P2.2（AI 智能故事规划器）已完成实施与工程自检（Prompt 工程与结构化 JSON 解析、候选严校验与单次带错自我修复、`planFunTextStory` 云函数与二次安全审核门禁、`creativePlannerClient` 客户端调度与规则静默降级闭环、本地开发调试离线模拟）。Task 6 云托管渲染器已补齐严格视觉字段、预览请求级回滚、审核响应严格类型映射和超限请求稳定 JSON 响应；缺失、空值、空字符串、字符串或未知 `errCode` 均关闭式失败。Task 8 候选页的低清预览降级现按项目单次触发，显式重试才会重新打开请求；服务端卡片 URL 只接受规范化后的 `https://`、`http://` 或 `cloud://`。Task 9 轻编辑页复核已改为 `movable-area` / `movable-view` 拖动生命周期：拖动中只按缩略图中心更新目标位置，结束时才单次提交排序；文字入口已统一为 `onEditText` 和 `onConfirmText`，确认文字后同步刷新对应缩略图而不改变拖拽状态。Task 10 结果页仅对渲染服务未配置或网络传输失败执行本地 Canvas 降级，审核与响应契约错误以及原型链/未知错误码保持关闭式失败；共享导出器拒绝 HTTP 非 2xx，穿搭内置资源恢复先复制到用户数据目录再保存。Task 11 记录恢复现用稳定渲染内容指纹证明缓存属于当前项目/候选/完整场景，只复用 trim 后的 HTTP(S)/Cloud 持久 URL；记录恢复、funtext canonical upsert 与请求 generation 均关闭式处理快照冲突、跨类型 ID 碰撞及旧异步回写。未知记录和未知趣味字画版本仍关闭式提示。分支内 180 项全量测试与语法/预检/文档检查均已通过。下一步继续推进 P2.3 轻量自由编辑或进入真机微信验收。

## 分支状态

- `main`：包含穿搭叠图主链路、既有内容安全能力和项目治理检查器；README 同步检查已启用。
- `codex/fun-text-stack-phase1`：包含 P1 分层换装底座、趣味字画阶段一（Task 1–12）及 P2.2 AI 智能故事规划器全套能力。本地调试环境已配置 `http://127.0.0.1:8080` 字体服务与渲染模拟；云托管渲染边界要求显式已注册字感和视觉包匹配背景，三候选预览任一后续失败会回滚本次请求全部既有上传，生产审核只接受数值型官方成功/不安全错误码。候选页低清降级对每个项目自动请求一次，服务端图片地址会先收紧并去除首尾空白；Task 9 缩略图排序已采用真实 WXML 拖动绑定并防止 `bindchange` / 重复结束事件重复移动，确认文字会同步刷新缩略图场景；Task 10 结果页的本地高清降级已收紧为 `FUN_RENDERER_NOT_CONFIGURED` / `NETWORK_ERROR` 的自有白名单，安全、响应、原型链与未知错误均不生成记录，趣味字画预览组名固定为“趣味字画”；Task 11 的缓存复用要求 task/record/card 稳定渲染指纹一致并仅接受持久 URL，记录重开保持单事件，canonical funtext upsert 不触碰跨类型或冲突记录，旧请求 generation 不能回写新结果。历史 bigtext 和未知类型均有关闭式兼容提示。分支内 180 项自动化测试已通过。
- `codex/layered-dressup-mvp`：保留分层云换装 MVP 的来源提交；其实现已集成至 `codex/fun-text-stack-phase1`，但尚未完成微信开发者工具、iOS、Android 和真实聊天验收，也尚未合并到 `main`。
- `codex/bigtext-handwrite`：保留旧大字滑卡、授权字体、马克笔渲染和贴纸技术实验；产品方向已由「趣味字画」替代，不再计划整体合并。
