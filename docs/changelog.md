# WePicTool 更新摘要

## Unreleased

### 用户体验

- 首页合入“分层换装 / 趣味字画”双玩法选择与共享预览，保留穿搭整理次级入口。
- 新增分层云换装：四个部位独立滑动、素材增删排序、微信叠图预览与按组保存。
- 新增趣味字画：12 个案例、8 种规则玩法、三套候选、7 套风格、3 种授权字感，以及内容/样式/装饰聚焦编辑。
- 趣味字画贴纸和涂鸦支持鲜明、浅色、透明共 24 色，并保持本地预览与最终渲染一致。
- 微信效果预览改为固定聊天外壳、普通/深色切换、自然牌堆滑动、展开/收起和真实比例消息图片。
- 三种玩法共用带 `01…N` 可见序号的导出、预览、串行保存和失败续存流程。
- 字体服务断连时改为服务端低清预览或保留编辑后重试，不再显示空白画布和底层网络错误。

### 内部工程

- 建立项目文档治理、每日迭代日志和文档同步检查机制。
- 大字滑卡方向已由趣味字画替代，不再计划整体合并。
- 趣味字画 P2.1/P2.3、分层云换装、共享首页、微信效果预览和统一导出已合并到 `main`；尚未完成 Docker、CloudBase 生产端点、iOS/Android、真实聊天或发布。
- 分支含计划外的 P2.2 AI 故事规划实验代码与自动化，但发布范围未确认；`planFunTextStory`、服务端模型 API key、线上域名和真机链路仍待办。
